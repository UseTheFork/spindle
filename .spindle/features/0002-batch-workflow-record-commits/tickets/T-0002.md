# Resolve canonical records from ticket worktrees

- **Reporter:** User
- **Category:** enhancement
- **Author:** Copilot

## Requirements

An authorized workflow command started in a ticket worktree shall resolve and use the canonical records in the matching feature worktree by using Git's registered worktrees and exact feature branch identity. Resolution shall validate repository, worktree, branch, and feature identity. It shall not use a committed absolute path locator or fall back to a ticket-worktree copy.

## Acceptance Criteria

- When an authorized workflow command runs from a ticket worktree, the system shall resolve the registered feature worktree for the ticket's feature and use its canonical records.
- When Git has a valid updated registration for a moved feature worktree, the system shall resolve its current location.
- When the feature worktree is missing, unregistered, unusable, or inconsistent with the expected repository, branch, or feature identity, the system shall report an error and shall not update another records copy.
- When a supported workflow command runs from the feature worktree, the system shall continue to operate on its canonical records.
- Tests using real Git worktrees shall verify successful resolution, moved-worktree resolution, and failure cases.
