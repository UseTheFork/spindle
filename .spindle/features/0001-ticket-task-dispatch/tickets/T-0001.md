# Manage task plans

- **Reporter:** User
- **Category:** enhancement
- **Author:** Copilot

## Requirements

Add CLI commands for the controller to create and update task definitions nested under a ticket in `sdd.json`. A task has a ticket-local `TASK-0001` ID, title, instructions, task-specific acceptance criteria, repository-relative edit/create/reference paths, dependencies on tasks in the same ticket, and an initial unassigned status. Validate required values, exact non-glob paths, unique IDs, dependency existence, and acyclic task dependencies. Do not add task sections to ticket Markdown or support direct ledger edits. This ticket establishes task definitions only; assignment lifecycle and concurrent file reservation are handled by dependent tickets.

## Acceptance Criteria

- When a controller creates a task, the system shall persist its definition under the selected ticket in `sdd.json` and return its ticket-local task ID.
- When a controller updates a task, the system shall persist only the requested task fields through the SDD command.
- When required task fields are missing or an edit/create/reference path is not a valid explicit repository-relative path, the system shall reject the command without changing the ledger.
- When a task dependency does not exist in the same ticket or creates a dependency cycle, the system shall reject the command without changing the ledger.
- When the controller creates a second task for a ticket, the system shall assign a distinct ticket-local task ID.
