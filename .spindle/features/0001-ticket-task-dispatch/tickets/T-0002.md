# Dispatch and accept tasks

- **Reporter:** User
- **Category:** enhancement
- **Author:** Copilot

## Requirements

Add the task assignment and controller review lifecycle for task definitions. Assigning a ready task records its assignment and returns a worker handoff with the task objective and acceptance criteria, parent ticket requirements and acceptance criteria, allowed edit/create paths, reference paths, shared ticket worktree, and unique report destination. Provide a read-only command to reproduce the handoff. The controller records report submission and either accepts the task or requests changes. Workers do not modify `sdd.json` or commit code. This ticket handles individual task lifecycle; cross-task concurrency reservations and dependency readiness are handled by the next ticket.

## Acceptance Criteria

- When the controller assigns an unassigned task, the system shall persist its assignment and return a self-contained handoff with all agreed task and parent-ticket context and the report destination.
- When the controller requests instructions for a task, the system shall return its current handoff without changing workflow state.
- When the controller records a task report, the system shall mark the task submitted and retain its assignment details.
- When the controller accepts a submitted task, the system shall mark it accepted.
- When the controller requests changes to a submitted task, the system shall mark it changes-requested and allow the task to be reassigned.
- When a worker identity attempts to change task workflow state, the system shall reject the command without changing the ledger.
