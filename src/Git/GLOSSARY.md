# Git

**Repository**:
The Git repository discovered from the invocation's explicit starting directory.

**Working tree**:
The checked-out files and their current content and modes, including uncommitted
changes. Its root is distinct from the invocation's starting directory.

**Index**:
Git's staged content and modes prepared for a future commit.

**Commit**:
A caller-created immutable history record identified by its object ID.

**Tree**:
The file paths, object identities, and modes recorded by a commit.

**Object ID**:
Git's identifier for stored content or history, independent of SDD evidence
snapshot hashes.
