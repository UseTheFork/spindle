# Feature-scoped issue tracking and completion

SDD tracks independently actionable work as feature-scoped issues with open, in-progress, or closed status; readiness and dependency blocking are derived from issue state. The feature owns the final review and verification gates: one comprehensive review is required by default, optional catalog-approved reviewer agents may be added, and relevant tests must pass before completion. Review findings return work to the affected issue; issue-level review, acceptance, and integration are not separate required lifecycles. Git commit and integration remain in the project's normal workflow after SDD completion.
