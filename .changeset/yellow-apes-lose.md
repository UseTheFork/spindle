Rebuild subagent-driven development around a CLI-managed work graph. Plan a feature from an optional design through its spec, tickets, and tasks, then use `spindle sdd next` to see which actions are available and why work is blocked. The updated SDD agents handle task execution, reviews, and merges through CLI-generated assignments.

This release replaces the legacy SDD commands and does not migrate existing SDD workspaces. Start new workspaces for the new workflow.
