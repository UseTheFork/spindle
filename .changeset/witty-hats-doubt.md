Expand SDD workflows with delivery ownership, ticket synchronization, assignment-based submissions, final-check revalidation, and improved recovery. SDD feature workspaces now use `.spindle/features/`; existing `.scratch/` workspaces must be moved manually. SDD command options now use `--feature` and `--actor` instead of `--spec` and `--author`; review no longer accepts `--inventory` or `--agent`.
